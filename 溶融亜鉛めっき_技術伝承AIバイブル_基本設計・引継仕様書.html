1.1 開発の背景と目的

溶融亜鉛めっき工場における品質管理・不具合対応は、熟練職人（村上本部長）の経験と感覚に依存しており、暗黙知のブラックボックス化が課題となっていました。若手・中堅（三浦さん）が現場で疑問を持っても、多忙な職人に気兼ねして質問できなかったり、口頭で教わったノウハウが記録に残らないという問題を、「AIインタビュー ＋ 専用誤変換辞書」により完全解決します。

🎯 コア運用フロー（負荷ゼロ設計）
  • 三浦さん（質問側）: 現場の気になる事象をスマホでメモ（「パイプの先が黒ずんでる」等の殴り書き）や写真添付で投稿。AIが職人向けに具体的・論理的な質問へ自動リライト。
  • 村上本部長（回答側）: 「🔊 質問を聞いて回答する」ボタンを1タップ。スマホが質問をAI音声で読み上げ、自動起動したマイクに向かって口頭で喋るだけ。
  • Gemini 1.5 Flash（自動構造化）: 現場用語辞書（リラックス➔フラックス等）を参照しながら自動補正し、【現象・原因・処置合否基準・再発防止策】に構造化してDB保存。

3.1 200問インデックスのカテゴリ構成 (JIS H 8641準拠)

  • CAT-1 前処理・薬品管理 (No.1〜35): 脱脂、酸洗、水洗、フラックス、鉄分濃度管理
  • CAT-2 めっき浴・浸漬作業 (No.36〜70): 浴温（445℃〜450℃）、アルミ/ビスマス添加、ドロス管理、灰払い、引上速度
  • CAT-3 後処理・冷却・防錆 (No.71〜105): 水冷、温水洗浄、空冷、クロメート/ノンクロメート処理、白サビ対策
  • CAT-4 外観欠陥・手直し基準 (No.106〜140): 不めっき、ヤケ、光沢ムラ、タレ、ツララ、ザラ肌、LME割れ
  • CAT-5 膜厚・試験・JIS規格 (No.141〜175): HDZ35/45/55、電磁式膜厚計5点平均、密着性・硫酸銅試験
  • CAT-6 再処理・特殊形状・安全 (No.176〜200): 閉鎖断面・空気抜き孔（水蒸気爆発防止）、酸剥離、ジンクリッチ補修

5.3 データベーススキーマ定義 (PostgreSQL)

-- 1. 質問キューテーブル (questions_queue) CREATE TABLE IF NOT EXISTS questions_queue ( id UUID PRIMARY KEY DEFAULT gen_random_uuid(), category_id VARCHAR(50) NOT NULL, -- 'CAT-1'〜'CAT-6' question_no INTEGER NOT NULL, -- 1〜200 title TEXT NOT NULL, -- 質問タイトル question_text TEXT NOT NULL, -- 具体的質問本文 (AIリライト後) raw_prompt TEXT, -- 三浦さんの初期入力テキスト photos TEXT[], -- 現場写真URL配列 is_answered BOOLEAN DEFAULT FALSE, -- 回答済みフラグ has_voice_answer BOOLEAN DEFAULT FALSE, -- 本部長音声回答有無 knowledge_id UUID, -- 紐づくナレッジID created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(), updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW() ); -- 2. ナレッジ蓄積テーブル (knowledge_records) CREATE TABLE IF NOT EXISTS knowledge_records ( id UUID PRIMARY KEY DEFAULT gen_random_uuid(), question_id UUID REFERENCES questions_queue(id) ON DELETE CASCADE, title TEXT NOT NULL, -- 質問タイトル category_id VARCHAR(50) NOT NULL, -- 'CAT-1'〜'CAT-6' question_no INTEGER NOT NULL, phenomenon TEXT NOT NULL, -- 【現象】 cause TEXT NOT NULL, -- 【原因】 treatment TEXT NOT NULL, -- 【処置・合否判定基準】 prevention TEXT NOT NULL, -- 【再発防止策】 raw_transcript TEXT, -- 文字起こし全文 audio_url TEXT, -- 本部長肉声録音URL (Supabase Storage) photos TEXT[], -- 写真URL配列 has_voice_answer BOOLEAN DEFAULT TRUE, created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW() ); -- 3. インデックス作成 CREATE INDEX IF NOT EXISTS idx_questions_cat ON questions_queue(category_id); CREATE INDEX IF NOT EXISTS idx_questions_no ON questions_queue(question_no); CREATE INDEX IF NOT EXISTS idx_knowledge_qid ON knowledge_records(question_id);
